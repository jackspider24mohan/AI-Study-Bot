# 🤖 AI Study Bot – Your Personal AI Learning Companion

An intelligent and interactive study assistant designed to help students learn smarter, manage their study schedules, track academic progress, and understand difficult concepts.

AI Study Bot combines personalized study planning, productivity tracking, interactive charts, and an AI-powered chatbot into a single learning platform.

---

## ✨ Features

### 📚 Personalized Study Assessment
- Evaluates students' daily study habits.
- Identifies study levels: Beginner, Intermediate, and Advanced.
- Provides personalized study recommendations.

### 🗓️ Smart Study Scheduling
- Generates study schedules based on the student's learning level.
- Helps balance study, rest, and recreational activities.
- Supports better time management.

### 📊 Study Progress Analytics
- Tracks daily study, rest, and play hours.
- Displays progress through interactive charts.
- Helps students understand their productivity patterns.

### 🤖 AI Study Assistant
- Interactive chatbot for answering study-related questions.
- Provides explanations, learning suggestions, and study tips.
- Includes rule-based responses when AI connectivity is unavailable.

### ⏰ Study Alarm System
- Set alarms for study, rest, and recreational sessions.
- Configure session start times and durations.
- Provides browser notifications and audio alerts where supported.

### 💾 Local Data Storage
- Saves study progress and chat history using browser local storage.
- Retains data between browser sessions on the same device.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/jackspider24mohan/AI-Study-Bot.git
```

### 2. Navigate to the Project Directory

```bash
cd AI-Study-Bot
```

### 3. Open the Application

Open `project-2.html` in your preferred web browser.

You can also open the project folder in Visual Studio Code and use the Live Server extension.

## 🔒 Privacy

Study logs and chat history are stored locally in the browser using LocalStorage. The application does not provide cloud synchronization by default.

Avoid entering sensitive personal information into the chatbot.
