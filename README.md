# 🤖 AI Study Bot

An AI-powered study assistant designed to make learning easier and smarter. It helps students understand concepts, access study assistance, and improve their learning experience.

## ✨ Features

- AI-powered study assistance
- Simple and user-friendly interface
- Interactive learning experience
- Student-focused design

## 🛠️ Technologies Used

- HTML
- CSS
- Python

## 📁 Project Structure


## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/jackspider24mohan/AI-Study-Bot.git
```

2. Open the project folder.
3. Open `project-2.html` in your browser.

## 🎯 Project Objective

To develop an intelligent study assistant that helps students learn effectively, understand difficult topics, and make education more accessible.
